# OpenWrt Studio для LuCI — 0.1.0 preview

Отдельная тема `luci-theme-openwrtstudio` и модуль `luci-app-openwrtstudio`.
Это предварительная веб-версия, а не полный перенос WPF-приложения.

## Возможности

- Тёмное оформление стандартных страниц LuCI с адаптацией к телефону.
- Живые показатели памяти, нагрузки, времени работы и аренды DHCP.
- Карта зарегистрированных VPN-служб procd.
- Единый вход в стандартные формы Wi-Fi, LAN/WAN, DHCP, firewall, пакетов,
  резервного копирования, Cron и диагностики. Эти настройки выполняет LuCI.
- Работа через существующую сессию LuCI; пароль SSH браузеру не нужен.
- Модуль имеет только права чтения system/info, system/board, DHCP и служб.

Пока не перенесены конструкторы Mihomo/Sing-box, подписки, автоматическая
установка ForkOP, Sentinel и собственные конфигураторы VPN из Windows.
Системный трей и уведомления Windows не применимы к LuCI.

## Совместимость и установка

Проверяется на OpenWrt 25.12 с современным ucode LuCI и luci-theme-bootstrap.
На 21.02/23.05 установка этого варианта не поддерживается.
Нужны `luci-base`, `luci-theme-bootstrap`, `luci-mod-status`, `luci-mod-network`,
`luci-mod-system`, `luci-app-firewall`. Необязательные страницы USB и пакетов
зависят от установленных модулей LuCI.

Перед установкой сохраните резервную копию конфигурации.
Распакуйте архив исходников на роутере, перейдите в его каталог:

```sh
sh scripts/install-luci-studio.sh
```

Скрипт не переключает тему автоматически. Выберите **OpenWrtStudio** в
**Система → Система → Язык и оформление**. Дашборд: **Studio** в верхнем меню.
Файлы устанавливаются напрямую, без регистрации в opkg/apk; это режим preview.
Makefile для интеграции пакетов в дерево LuCI также включён.

Возврат исходной темы:

```sh
sh scripts/restore-luci-theme.sh
```

Исходная тема хранится в `/etc/openwrtstudio-luci-original`, копия настроек
LuCI — в `/etc/openwrtstudio-luci-config.backup` (доступ только root).
Возврат темы сохраняет установленный модуль Studio.

## Лицензии

Новый код: MIT, как OpenWrt Studio. При установке используются неизменённые
шаблоны и значки Bootstrap из установленного LuCI; их авторские права и
Apache-2.0 сохраняются в исходных файлах upstream.
