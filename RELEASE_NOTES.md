# OpenWrt Studio v2.5.20

Проверено 19.10.2026 на реальном роутере и Android-телефоне: переключения подтверждены независимым чтением состояния, исходный VPN и тема восстановлены. Подробности: [VPN_VALIDATION.md](VPN_VALIDATION.md).

Исправлено отображение и переключение VPN/ForkOP:

- Группы, их имена и порядок выбора читаются из конфигурации, кэшей и живого API. Четыре заранее заданные группы больше не создаются.
- Выбранный путь вычисляется от корня маршрутизации через вложенные селекторы. Неактивные группы и похожие имена не подменяют текущий сервер.
- Direct/bypass/reject исключены из VPN-серверов. Поддерживаются несколько последовательных JSON-кэшей.
- Удалены демонстрационные серверы/подписки и случайные задержки. Неизвестное время отображается как N/A.
- Команда переключения отправляется только в фактический селектор, содержащий нужный raw tag. Успех подтверждается новым снимком роутера; до этого активные метки не меняются.
- Добавлены общие сценарии с Android и независимые от WPF тесты парсера/команд.

Linux GUI собирается из Flutter-версии в [OpenWrtStudio-Mobile](https://github.com/RichkovGit/OpenWrtStudio-Mobile), с AppImage/tar.gz и отдельной инструкцией. WPF-приложение остаётся Windows-приложением.

# OpenWrt Studio v2.5.19

Обновлённый обзор сети, отчёт для поддержки и исправления сохранения настроек роутера, SSH, профилей и обновлений приложения.

## Интерфейс и новые функции

- Новый стартовый экран с подсказками подключения, созданием профиля и поиском роутера. Карточки ресурсов появляются после получения данных; при отключении старые показатели очищаются.
- В обзоре сети отображается время последнего снимка. Обновления данных не накладываются друг на друга, а результат старого подключения не подменяет данные нового.
- Кнопка «Сохранить отчёт» создаёт текстовую сводку модели, прошивки, загрузки CPU, RAM и overlay. Профили подключения, hostname, имена сетей, IP/MAC-адреса, пароли и ключи в отчёт не включаются.
- Быстрая навигация: `Ctrl+1` — обзор, `Ctrl+2` — клиенты, `Ctrl+3` — диагностика, `Ctrl+,` — настройки.
- Исправлены переключение светлой/тёмной темы и сохранение настройки автоматической проверки обновлений.

## Настройки роутера

- Сохранение Wi-Fi и проброса портов корректно обрабатывает анонимные UCI-секции. Значения SSID и паролей с апострофами читаются без обрезания.
- Сохраняется признак скрытой Wi-Fi-сети; при переходе на открытую сеть удаляется прежний ключ.
- Изменения статических DHCP-аренд применяются к роутеру. Повторное сохранение обновляет созданные записи. Сохранение требует успешного первоначального чтения и останавливается, если список секций изменился вне приложения.
- При чтении статического WAN восстанавливаются IP, маска, шлюз и DNS, включая список DNS-серверов.
- Ошибки промежуточных команд UCI прекращают выполнение сценария и передаются пользователю.
- В AmneziaWG проверяется имя интерфейса перед формированием команд, поддерживается endpoint вида `[IPv6]:port`, применяются импортированные DNS и корректнее удаляются связанные peer-секции.

## Надёжность

- SSH-подключение и резервная передача файлов через SSH меньше блокируют интерфейс. Загрузка через SSH выполняется частями во временный файл с заменой назначения после успешного декодирования; сохраняются права существующего файла и учитываются символические ссылки.
- Профили сохраняются через временный файл с резервной копией. Ошибки записи больше не сопровождаются сообщением об успешном сохранении.
- Исправлены остановка фонового мониторинга, освобождение обработчиков трея и сообщения о результате быстрых действий.
- Использование RAM рассчитывается с учётом `MemAvailable`; резервное чтение сетевых интерфейсов показывает полученные адреса вместо подставленных значений. Очистка DNS-кэша отправляет dnsmasq сигнал HUP.
- Проверка обновлений различает ошибки сервера и отсутствие релиза. При загрузке проверяются источник, размер и сигнатура формата файла; незавершённые загрузки удаляются. Для Portable ZIP открывается папка с архивом, приложение остаётся открытым до ручной замены.
- Исправлены пути проектов и тестов; добавлен Windows CI с .NET 8, тестами и сборкой Portable.
- Добавлен установщик Windows для текущего пользователя: корректная версия, файлы из корня Portable-сборки, лицензия и значок. Ярлык рабочего стола и автозапуск в трее включаются по желанию. Сохранён идентификатор приложения для обновления прежней установки; профили в AppData не удаляются.

## Проверка выпуска

Прошли **124 автоматических теста без подключения к роутеру**. В обычном запуске отдельно отключены 5 интеграционных проверок, требующих явного включения. Дополнительно прошли **2 проверки чтения реального роутера**: получение сведений и проверка Sentinel.

Эти проверки покрывают выбранные сценарии и не подтверждают совместимость со всеми прошивками, пакетами и моделями роутеров. Изменения сетевой конфигурации на реальном оборудовании в рамках этой проверки не выполнялись.

## Загрузка и обновление

- **`OpenWrtStudio_v2.5.19_Portable.zip`** — автономная сборка для Windows 10/11 x64; отдельно устанавливать .NET не требуется.
- **`OpenWrtStudio_Setup_v2.5.19.exe`** — установщик для текущего пользователя, без обязательного автозапуска.
- **`SHA256SUMS.txt`** — контрольные суммы файлов этого выпуска.

Скачайте нужный вариант из [релиза v2.5.19](https://github.com/RichkovGit/OpenWrtStudio/releases/tag/v2.5.19), проверьте SHA-256 и завершите старую копию приложения через меню трея «Выход». Закрытие окна крестиком оставляет приложение работающим в трее. Затем запустите установщик либо распакуйте архив в новую папку и запустите `OpenWrtStudio.exe`. Обычные профили и настройки хранятся в `%APPDATA%\OpenWrtStudio` и сохраняются при установке и удалении программы.

Установщик размещает программу в `%LOCALAPPDATA%\Programs\OpenWrt Studio`; права администратора для такой установки не нужны.
