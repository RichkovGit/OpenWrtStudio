# OpenWrt Studio LuCI v1.0.0-rc1

Первый кандидат темы и приложения OpenWrt Studio для веб-интерфейса роутера. Это отдельный комплект для LuCI, а не обновление Windows-приложения v2.5.19.

- Светлая/тёмная тема с адаптивными карточками и горячими клавишами.
- Обзор загрузки, RAM, overlay, времени работы и DHCP-клиентов; отчёт для поддержки без адресов клиентов, паролей и ключей.
- Карта возможностей, управление установленными службами и диагностика WAN/DNS/маршрутов.
- Импорт WireGuard/AmneziaWG: несколько peer, DNS, IPv6 endpoint и параметры обфускации. Изменения проверяются и применяются через LuCI.
- Конструктор Mihomo с подпиской и двумя пресетами; конфигурация проверяется ядром и сохраняется с резервной копией.
- Генератор Sing-box для VLESS Reality, Hysteria 2 и TUIC с проверкой ядром.
- Импорт клиентского OpenVPN со встроенными сертификатами; сценарии и плагины из импортируемого профиля не выполняются.
- Подключение Tailscale (Auth key, Exit Node, подсети) и ZeroTier.
- Фоновый Sentinel с повторными проверками и паузой между восстановлениями. По умолчанию выключен.
- Доступ к штатным настройкам Wi-Fi, WAN/LAN, DHCP, брандмауэра, cron, пакетов, резервного копирования и USB; предложение источника ForkOP по архитектуре.

IPK предназначены для проверки на OpenWrt 24.10 с современным LuCI и opkg. Для apk-прошивок используйте исходники и SDK своей версии. Пакеты протоколов и ядра VPN устанавливаются отдельно.

Прошли проверки синтаксиса, браузерные сценарии на фиктивных RPC-ответах, изолированные проверки RPC-обработчика и Sentinel, сборка и проверка структуры IPK. На реальном роутере установка, работа ucode-шаблонов, протоколов и маршрутизации пока не проверены. Полная идентичность всех функций настольной программы не заявляется. Подробности установки и ограничения — в README комплекта.

Файлы: `luci-theme-studio_1.0.0~rc1-1_all.ipk`, `luci-app-studio_1.0.0~rc1-1_all.ipk`, архив исходников и SHA256SUMS.txt.
